# 🚀 START HERE - FutureMind Fitness & Study Hub

Welcome! This guide will get you running in **2 minutes**.

## ⚡ Quickest Start (30 seconds)

### Windows Users
1. **Double-click** `RUN.bat`
2. Wait for "Starting FutureMind Server"
3. Open browser: `http://localhost:5000`

### Mac/Linux Users
1. **Open terminal** in this folder
2. Run: `bash RUN.sh`
3. Open browser: `http://localhost:5000`

## 🎨 Customize Colors (Easy!)

1. Open `static/style.css`
2. Find `:root {` at the top
3. Change these colors:

```css
:root {
    --primary: #ff2d95;    /* Change this to #00ff00 for green, #ffff00 for yellow, etc */
    --secondary: #8a2be2;
    --accent: #00bfff;
}
```

**Save file** → Refresh browser → See changes!

## ❓ Common Questions

### Q: Where is my data saved?
**A:** In `data.json` file. You can backup this file to keep your data safe.

### Q: Can I delete my data?
**A:** Delete `data.json` and restart the app. A new empty file will be created.

### Q: Can I add more exercises?
**A:** Yes! Edit `static/script.js` and find the `exercises` object.

### Q: Can I add more avatars?
**A:** Yes! Edit `static/script.js` and find the `avatarData` array. Add new emojis!

### Q: Why isn't it working?
**A:** Check QUICKSTART.md "Troubleshooting" section.

### Q: Can I deploy this online?
**A:** Yes! See TECHNICAL.md "Deployment Options" section.
